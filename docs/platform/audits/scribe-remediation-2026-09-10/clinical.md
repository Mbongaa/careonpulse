# Clinical extraction and model-ingress remediation

Date: 2026-09-10. Scope: audit findings C01–C09 in `docs/platform/SCRIBE_AUDIT_2026-09-10.md`.

Implemented in `src/lib/careon-scribe/deterministisch.ts`, `klinische-staat.ts`, and `agent.server.ts`. Added the executable regression suite `src/scripts/verify-scribe-clinical.ts`. No live provider calls, real patient data, production writes, or schema changes were performed by this workstream.

## Changes

| Finding | Change and acceptance evidence |
| --- | --- |
| C01 medication/dose association | Medication spans are ordered and each dose is associated with its adjacent medicine, including explicit prefix doses. Decimal comma and decimal point are preserved through clause splitting; spoken Dutch numbers continue to work. Tests cover different doses in both orders, prefix doses, mixed decimal notation, an un-dosed medicine next to a dosed medicine, hypothetical usage and an explicitly proposed change. |
| C02 normal findings | Sleep/appetite symptom detection now requires an actual abnormal finding. Normal sleep, normal appetite and weight gain do not create those symptoms. Genuine poor sleep, reduced appetite, no appetite and ordinary symptom negation remain supported. |
| C03 questions/history/hypotheticals | Assertions are split with question punctuation retained and explicit subject changes recognized. Questions cannot populate confirmed allergies, duration/severity, objective measurements or plans/tasks. Historical and hypothetical statements cannot create current symptoms or future task commitments. Lifestyle questions retain a discussed-topic marker without an asserted quantity. Positive confirmed allergy and actual lab-request tests ensure the fix does not simply disable extraction. |
| C04 experiencer | Clauses about family members are retained as family history and excluded from the patient's medication/symptom/scalar extraction. An explicit subsequent patient subject is processed independently. Family history is present in SOAP/general anamnesis report material. |
| C05 English fallback | All deterministic entry points accept session language. For English, the Dutch heuristic parser does not infer new clinical facts. A clear manual-review notice is returned; all deterministic report sections have empty text, `status=leeg`, and `vereistBehandelaar=true`. Earlier facts remain available as clearly labeled context. Normal bulk approval must skip these sections; the backend/UI workstreams own those approval guards. The model-ingress path still accepts supported literal English evidence conservatively, with an English current-medication positive test. |
| C06 ordering and corrected-source replay | Safe dictionary corrections and speaker assignments are applied to cloned effective segments before extraction, so a final fragment produces its facts and medication-rule result immediately. `heranalyseStartStaat(previous)` clears machine-derived state before an authoritative transcript/speaker correction is replayed while preserving all `doorBehandelaar` facts, including clinician intrekkingen. Server/UI invoke it only on correction replay; ordinary new fragments retain prior state, including an AI-only medicine. Regression cases replace a medicine and dose, remove a family-attributed allergy, remove stale warnings and preserve clinician facts. |
| C07 source binding | Model facts require nonempty positive existing transcript sources. Newly inferred scalar values and narrative fields require canonical deterministic support or a complete literal statement, with speaker/experiencer/question/history restrictions. Medication name, dose, usage and narrative must agree with their source; a task's description/kind and a categorized fact's category are checked separately. Model ownership flags and derived dosage extensions are not trusted. Arbitrary model transcript rewrites are rejected; only deterministic dictionary corrections are accepted. Null/nonobject speaker and correction array entries are ignored, and malformed state falls back safely. The final report model is now independently constrained to complete canonical section content and its complete existing source set; only verifiable formatting changes are accepted. Additions, omissions, dose changes and changed negation fall back to canonical content. Null/nonobject report rows also fall back safely. |
| C08 risk polarity and ownership | Newly generated machine scalars and all rendered fact text fields—including task descriptions—pass through the risk-topic normalizer. English risk expressions are included. Machine statements become a discussed-topic marker requiring clinician assessment. Explicit clinician `doorBehandelaar` facts are preserved, as are existing scalar assessments during ordinary finalization/analysis. Generic merge now preserves clinician facts in replaceable categories as well as additive ones. |
| C09 cessation consistency | A later explicit cessation retracts the earlier inferred current-use row; the stopped row remains visible. A later explicit restart can reactivate the current row and retract the old stopped row. This works within a complete transcript and across incremental merges. Obsolete current medication no longer causes an interaction warning. Clinician-authored medication facts are protected from automatic overwrite. |

The model prompt version is now `careon-scribe-2026-09-10.2`.

## Interfaces coordinated with other workstreams

- The optional final `taal: ScribeTaal = "nl"` parameter is available on `extraheerDeterministisch`, `deterministischeRonde`, and `bouwVerslagDeterministisch`; server and demo callers should pass session language.
- English deterministic report creation requires every section to remain manually required. The backend workstream confirmed enforcement at note creation/patch/bulk approval; the UI workstream confirmed manual sections are skipped by bulk approval.
- `heranalyseStartStaat(previous)` must run exactly once before replaying all effective segments after authoritative transcript/speaker correction. The backend uses the correction-invalidated state with `verouderd=true` and rewound `laatsteSegment=0`; subsequent replay chunks remain additive. The demo workstream uses the same helper.
- Clinical scalars have no persisted authorship marker and no supported scalar-edit API/UI today. They are cleared and re-derived during authoritative correction replay. Actual clinician fact rows are preserved, and clinician-authored note sections live outside this state. Ordinary finalization does not silently normalize/strip an existing scalar assessment. No new scalar ownership contract was introduced.

## Limits

This is engineering regression evidence, not clinical certification, diagnostic validation or a recall benchmark. The deterministic parser remains a limited Dutch heuristic system; ambiguous family clauses, unknown terminology and unsupported paraphrases may be omitted rather than asserted. The model-ingress restrictions deliberately reduce unverified paraphrasing and may require more manual completion. Report rewriting is restricted to complete canonical wording, with case/whitespace and cliënt/patiënt formatting equivalence; clinical paraphrases require clinician editing. English deterministic processing explicitly requires manual completion of every report section. A valid citation and literal quote do not establish that the underlying transcript or speaker assignment is clinically correct; clinician review is still required. Historical persisted machine state is not backfilled by these code changes and should be rebuilt from its effective transcript when authoritative corrections invalidate it. Browser/database integration and source-version approval guarantees are verified by the coordinating workstreams, not independently claimed here.
